# 🌹 Birthday Experience for Shahd | From Omar

A luxury, romantic, interactive birthday web experience built with React, Vite, and Tailwind CSS. Specially crafted by Omar for Shahd's birthday (November 1st).

---

## ✨ Experience Journey

1. **Screen 1 — Hero Intro (`HeroIntroCard`)**:
   - Romantic animated greeting with alternating typography.
   - Interactive peeking cats with sound effects.
   - Falling rose petals ambient background.

2. **Screen 2 — Retro Y2K CD Player (`CDPlayerStage`)**:
   - Interactive mechanical CD insertion with authentic sound effects.
   - Tonearm drop and playback of *Lovesong*.
   - Floral watercolor theater curtain transition.

3. **Screen 3 — Cake Celebration & Your Gifts (`CakeAndGiftsStage`)**:
   - Interactive birthday cake with candles.
   - Celebration confetti cannons & smooth fade-in to the 4 special gifts:
     - 🌹 **Gift 1 — Bouquet of Flowers (`BouquetGiftCard`)**: Interactive mini-game to collect scattered roses and reveal a luxury blooming bouquet.
     - ✨ **Gift 2 — You Wish (`YouWishGiftCard`)**: Holographic constellation network with Omar's wishes, draggable canvas, and custom PNG card download.
     - 🎵 **Gift 3 — Playlist (`PlaylistGiftCard`)**: Spotify embed player in a rose-gold card with dancing cat GIF and automatic background music pause/resume.
     - 💌 **Gift 4 — Love Letter (`MessageGiftCard`)**: 3D interactive red wax-sealed envelope with smooth flap flip and Omar's heartfelt personal letter.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

- **React 18**
- **Vite**
- **Tailwind CSS**
- **Lucide React Icons**

- **Web Audio API** (Custom zero-dependency sound synthesis)
